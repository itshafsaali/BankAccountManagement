# Bank Account Management System

A beginner Python project that demonstrates Object-Oriented Programming (OOP) concepts through a simple bank account simulation.

## Features

- Create bank accounts with account number and balance validation
- Prevent duplicate account numbers
- Deposit and withdraw money with basic validation
- Access account balances through a property
- Create savings accounts using inheritance
- Calculate savings account interest
- Compare accounts by account number and compare their balances
- Retrieve and update the bank name using class methods
- Track the total number of accounts created

## OOP Concepts Demonstrated

- Classes and objects
- Constructors
- Encapsulation
- Inheritance
- Class methods and static methods
- Properties
- Method overriding
- Special methods (`__str__` and `__eq__`)

## Requirements

- Python 3
- No external libraries required

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

   python bank_account.py

## Limitations

This is an educational simulation, not a real banking application. It does not connect to a bank, permanently store account records, or provide production-level financial security.

## Learning Purpose

This project was created to practice Python OOP concepts, input validation, inheritance, and basic account operations.
